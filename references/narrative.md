# 论文叙事：读者应该能复述的故事

目标是恢复作者的论证路径，并让没有读过论文的人听懂；不是润色论文摘要，也不是为结论制造戏剧性。先读原文和证据账本，再写故事。题目和摘要提供候选主线，方法、结果和局限决定这条主线是否成立。

## 找到主线

用具体句子回答六个问题，每个实证判断要能回到页码或图表：

1. **世界与旧办法**：研究发生在什么问题情境？过去通常怎么处理？“通常”若只来自作者的叙述，要标为作者的概括。
2. **缺口与张力**：已有办法具体遗漏了什么？用一个读者能理解的问题表述；不要把尚未测试的假设提前写成事实。
3. **关键动作**：作者为了分辨可能解释，实际做了什么？明确谁/什么被观察、什么被操纵、比较什么。用通俗语言保留识别逻辑。
4. **证据推进**：哪些结果回答了问题，哪些结果没有达到预期或仍有不确定性？所谓“转折”必须由实际证据支持；没有转折时用逐步累积的说明。
5. **有边界的回答**：读者现在能相信什么、仍不能断言什么？将最强发现与最诱人的过度解读并排核对。
6. **意义与下一步**：这改变了哪个具体认识、带来什么新问题？把作者提出的建议与已经检验的干预分开。

可用 What / Why / How / So what 做自检：做了什么、为什么值得做、证据如何支持、读者因此应如何理解问题。它们是检查问题，不必成为生硬的四个标题。

## 独立文件夹的输出

在 `08_论文叙事/content.json` 中至少包含：

- **一句话主线**：具体问题＋研究动作＋有限定的答案，避免只有“提出一种新方法”。
- **短讲版本**：约 1–3 分钟口述长度，默认约 400–700 个汉字，按实际复杂度调整。先讲人面对的难题，再介绍方法名称。
- **完整故事**：从情境、问题、调查动作到证据和边界，连贯成文。不要让每段都成为术语清单。
- **章节与故事对照表**：论文章节/页码 → 在故事中的作用 → 关键证据 → 不能跳过的限定。
- **易误读点**：列出最容易把故事讲歪的 3–5 个地方，例如将预测当因果、把统计不显著当没有效应、将示例当普遍结果。
- **复述题**：先让读者不用术语讲清问题与方法，再给可折叠的参考答案；答案保留边界。

只在确实帮助理解时用一个明确标注的教学类比，并说明类比失效处。真实研究过程不必服从“英雄克服困难”的模板；不能编造研究者心理、失败实验、人物对白、学界共识或未出现的数据。

## 按论文类型调整

- 实证研究：问题 → 可区分的解释 → 设计 → 观察 → 解释边界。
- 理论论文：旧概念的困难 → 假设/定义 → 推导 → 条件下成立的结论 → 反例或适用域。
- 方法论文：任务瓶颈 → 方法关键差异 → 公平比较 → 性能/成本/失败情形 → 适用条件。
- 综述：分散的问题 → 组织框架 → 不一致的证据 → 已知与未知；不能套成作者新做了一次实验。

## 审读准则

让另一位未参与撰写的审读者（或一次明确标注的单独自审）只看故事、证据账本和原文，检查：每个叙事节点有来源；通俗化未改变研究对象和比较；主结果、探索性结果及建议没有混用；反直觉处不是修辞制造；听完能说出至少一个结论边界。记录具体问题和修复，不用“优秀”等主观评分代替证据。
